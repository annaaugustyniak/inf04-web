# GIT COMMANDS - explained

Przydatne komendy:

`git init` - tworzy repozytorium
`git status` - pokazuje status aktualnego brancha (jakie pliki zostaly stworzone/edytowane, ale nie zacommitowane)
`git switch [branch_name]` - zmienia uzywan branch na [branch_name]
`git switch -c [branch_name]` - tworzy i zmienia uzywan branch na [branch_name]
`git commit -m "[message]"` - wykonuje commit z tytulem podanym w [message]
`git merge [branch_name]` - wczytuje zmiany z [branch_name] na aktualnie uzywany branch
`git config --local user.name "[name]"` - ustawia w pliku konfiguracyjnym imie uzytkownika
`git config --local user.email "[email]"` - ustawia w pliku konfiguracyjnym email uzytkownika
`git add [filename]` - dodaje plik do commita
