# GIT COMMANDS - explained

Przydatne komendy:

`git init` - tworzy repozytorium
`git status` - pokazuje status aktualnego brancha (jakie pliki zostaly stworzone/edytowane, ale nie zacommitowane)
`git switch [branch name]` - zmienia uzywan branch na inny
`git commit -m "[message]"` - wykonuje commit z tytulem podanym w [message]
